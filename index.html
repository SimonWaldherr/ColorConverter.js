ColorConverter.js

A tiny JavaScript library for converting between RGB, HSL, HSV, YUV, CMYK and HEX color spaces.

Live demos

  • ConverterConvert a single color between every supported format.
  • ParserParse #hex, rgb(), hsl(), yuv() and cmyk() strings.
  • BoxesRandom color palette using every conversion in turn.
  • MixBlend a base color with random samples.
  • Gradient (RGB)Generate gradients from RGB sliders.
  • Gradient (HSL)Generate gradients from HSL sliders.
  • SlidersInteractive RGB / HSL / YUV / HSV / CMYK sliders.
  • ComplexityVisualize a string’s “complexity” score as a color.
